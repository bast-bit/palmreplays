Privacy Policy

PalmReplays Tools · Effective 18 November 2026

What this app is

PalmReplays Tools is a private, read-only tool. The owner of the YouTube channel PalmReplays uses it on his own computer to read his own channel's statistics. It is not offered to the public and has no other users.

Data accessed

With the user's consent, the app requests two read-only permissions from Google:

  • youtube.readonly: channel details, the list of uploaded videos, video statistics and public comments.
  • yt-analytics.readonly: YouTube Analytics reports for the user's own channel, such as views, watch time and audience retention.

The app cannot upload, change or delete anything on YouTube.

How the data is used and stored

  • The data is only used to show the channel owner his own statistics.
  • It is processed and stored only locally on the owner's computer. The login token is stored in a local file there.
  • It is not sold, shared or transferred to third parties, and it is not used for advertising or to train AI models.

PalmReplays Tools' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

You can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored access, and stored statistics can be deleted the same way.

Contact

Questions can be sent through the PalmReplays YouTube channel.
